# Safe, Short, and Tight Profiles

## Objective
Implement safe, short, and tight profiles without changing semantics.

## Experiment Design

### Dataset
- `datasets/dev/multilingual-core-v1.jsonl` - Multilingual core dataset for testing

### Hypothesis
Safe, short, and tight profiles will reduce token usage while preserving semantic meaning and accuracy.

### Implementation Plan

1. Create profile types
2. Implement safe profile
3. Implement short profile
4. Implement tight profile
5. Create measurement tests
6. Create documentation

## Expected Outcomes

- Profile types definition
- Safe profile implementation
- Short profile implementation
- Tight profile implementation
- Measurement test suite
- Documentation

# Natural development v7

This is a diagnostic development task for issue #685. It is not protected
evaluation data and is not training data. The corpus is frozen before source-
only extraction. English alternatives were authored independently from the
Greek realizations; the Greek rows require language-quality review before any
multilingual claim.

The task has six parse groups (three rows each: two English realizations and
one Greek realization) and two abstention groups (three rows each), for 24
rows. Contrast labels and the source-to-target map remain private metadata.
Exact identity is permitted only for source-visible literals and task-frozen
role types. Prompt-level isolation is the only isolation claimed unless the
extraction record proves stronger containment.

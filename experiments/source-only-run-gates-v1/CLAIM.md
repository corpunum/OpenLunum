# Scope of this experiment

Deterministic evidence gates and a source-only disposition review, not a live
extraction result. No semantic registry, frame, prompt convention, schema or
fingerprint change is proposed. No model/provider call is authorized by this
manifest. A subsequent live experiment needs its own frozen source population,
model identity, budget and evidence.

The 14 visible unresolved diagnostic sources are reviewed without making the
historical parse expectations disappear. Source-relative representation options
are not protected gold, human adjudication, native-speaker certification, shared
cross-language entity grounding, or proof of semantic correctness.

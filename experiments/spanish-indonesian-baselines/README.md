# Spanish and Indonesian Parse Baselines

## Objective
Establish Spanish and Indonesian parse baselines to expand multilingual coverage and enable consistent semantic parsing across these languages.

## Experiment Design

### Dataset
- `datasets/dev/multilingual-core-v1.jsonl` - Multilingual core dataset for testing

### Hypothesis
Establishing Spanish and Indonesian parse baselines will expand multilingual coverage and enable consistent semantic parsing across these languages.

### Implementation Plan

1. Create Spanish parse baseline rules
2. Create Indonesian parse baseline rules
3. Add language-specific parsing features
4. Create test suite for both languages
5. Document parsing patterns for both languages

## Expected Outcomes

- Working Spanish parse baseline
- Working Indonesian parse baseline
- Consistent parsing across 4 languages
- Test suite for both languages
- Documentation for Spanish and Indonesian patterns

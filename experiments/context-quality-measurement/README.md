# Context Quality Measurement

## Objective
Measure natural vs Lunum vs mixed context downstream quality.

## Experiment Design

### Dataset
- `datasets/dev/multilingual-core-v1.jsonl` - Multilingual core dataset for testing

### Hypothesis
Lunum context will provide better downstream quality than natural language context, with mixed context offering the best balance.

### Implementation Plan

1. Create context measurement framework
2. Implement natural language context
3. Implement Lunum context
4. Implement mixed context
5. Create measurement tests
6. Create documentation

## Expected Outcomes

- Context measurement framework
- Natural language context implementation
- Lunum context implementation
- Mixed context implementation
- Measurement test suite
- Documentation

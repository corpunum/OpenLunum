# Human source review packet

These 14 English/Greek sources are already-visible unresolved diagnostic
cases, not new protected evaluation data. All reviews are **pending**. This
packet supplies no previous model output, proposed Sem, expected outcome, or
model-generated disposition. It does not certify gold or change old scores.

For each source, an identified human reviewer should describe the meaning in
their own words and list separately:

- Who acts or experiences; what is acted on; who receives it; any direction.
- Restrictions, exceptions, scope, conditions, order, recurrence, and time.
- Negation, requirement, permission, possibility, ability, and uncertainty.
- Names, identifiers, numbers, units, dates, and whether anything is unstated.
- Plausible alternative readings or context needed to disambiguate.

Do not invent a missing unit, year, actor, authorization, referent, or context.
A fluent/native Greek reviewer is needed for the Greek sources. Review the
source meaning first, independently from whether the current protocol can
encode it. A later technical review must map only that supported meaning to
the versioned contract, or retain natural text when it cannot do so faithfully.

Please return a new reviewed artifact with reviewer identity/role, actual
language competence, timestamp, and the supplied source hashes. Do not replace
this pending packet. Model-generated feedback must not be labelled human or
native review. Subsequent code motivated by this diagnostic review will still
need a fresh independently authored protected corpus before quality claims.

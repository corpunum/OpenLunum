# Natural development v6

This is a small, development-only successor task for issue #680. It is not
protected evaluation or training data.

The task intentionally uses source-visible stable names and identifiers so
source-relative meaning is answerable and some exact identity comparisons are
legitimate. The task contract fixes the event-level kind and role type policy;
those rules must not be generalized beyond this task. Targets require fresh
independent review before freezing. Extraction must be performed by a fresh
agent with only the opaque request, source language/text, and frozen public
contracts. Private dataset metadata and contrast definitions are never part of
the extractor packet. Isolation is prompt-level unless a stronger boundary is
recorded.

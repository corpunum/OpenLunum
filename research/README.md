# Research archive

The active GitHub tree preserves the principal initial handover document, its file inventory, and the complete extracted Lunum 2.7 working package under `archive/initial-handover/`.

The original uploaded handover ZIP SHA-256 was:

```text
344a8bb5fe97818ad39d4d9e13ef2c27600ac4f3c2995e85c5deb7658e6673e8
```

The preservation bundle maintained with the project also contains redundant historical extracted trees and binary version ZIP snapshots. Those duplicate binary snapshots are intentionally not committed to the active Git history; their names and original checksums remain documented in `FILE-INVENTORY.md` and the original manifest retained with the preservation artifact.

Historical material is evidence and design history, not the active package source. Active implementation lives under `packages/`, schemas under `schemas/`, and current decisions under `docs/`.

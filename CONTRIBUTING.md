# Contributing

OpenLunum is currently a private, evidence-driven project.

A change is ready for review when it includes:

- a clearly stated semantic or integration goal;
- tests or reproducible evaluation steps;
- no unsupported performance claims;
- migration notes for schema/fingerprint changes;
- a named tokenizer/model environment for renderer results;
- updated product/version metadata for integration changes.

Use conventional commit subjects where practical, for example `feat(core):`, `fix(renderer):`, `docs(openunum):`, and `eval(supergemma):`.

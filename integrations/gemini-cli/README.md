# Gemini CLI / successor adoption profile

**Status:** Design. Gemini CLI documentation currently advertises MCP servers, extensions, Agent Skills, hooks, and project `GEMINI.md`; its public transition notices mean tested product versions must be pinned and rechecked.

Preferred options:

- MCP server for explicit Lunum operations and resources.
- Extension bundling commands, hooks, context files, and MCP configuration.
- `GEMINI.md` for repository adoption instructions, not as a substitute for runtime integration.

Official references:
- https://geminicli.com/docs/tools/mcp-server/
- https://geminicli.com/docs/extensions/

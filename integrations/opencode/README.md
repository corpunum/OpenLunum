# OpenCode adoption profile

**Status:** Design, based on official plugin and MCP documentation.

Preferred options:

- Plugin for lifecycle-aware context handling and telemetry.
- MCP server for explicit Lunum tools when a plugin should not embed the SDK.
- Repository instructions for agents implementing Lunum in another product.

A plugin must expose clear opt-in behavior, source retention, and a removal path.

Official references:
- https://opencode.ai/docs/plugins/
- https://opencode.ai/docs/mcp-servers/

# Quality Gate CI Integration

## Purpose

Runs quality gates on every PR that touches `packages/core/src/` or `packages/eval/src/`.
Integrates downstream-quality, prompt-injection, and renderer-conformance into a
unified CI pipeline.

This module implements the WORK_QUEUE v4 release gate 5 item:
"Quality gate CI integration: run quality gates on every PR that touches
packages/core/src/ or packages/eval/src/."

## Motivation

CI systems need to know whether changes pass quality gates before merging.
The quality gate CI integration provides:

1. **Unified gate runner** — runs all quality dimensions in one pass
2. **Configurable gates** — enable/disable specific gate types
3. **Exit codes** — 0 (pass), 1 (warn), 2 (fail) for CI integration
4. **CI report** — markdown report for pull request comments

## Gates

| Gate | Description | Default |
|------|-------------|---------|
| `sem-validation` | Validates sem structures through validateSem | Always |
| `injection-resistance` | Runs prompt-injection tests (10 adversarial inputs) | Yes |
| `renderer-conformance` | Runs renderer conformance suite | Yes |
| `downstream-quality` | Runs downstream quality evaluation | Yes |
| `context-quality` | Compares natural vs Lunum vs mixed context | Optional |

## API

### runQualityGates()

```typescript
import { runQualityGates, getDefaultGates, type QualityGateCIConfig } from '@corpunum/lunum';

const config: QualityGateCIConfig = {
  runInjectionTests: true,
  runConformanceSuite: true,
  runDownstreamQuality: true,
  runContextQuality: false,
  minimumPassRate: 0.8,
  strictMode: false
};

const result = runQualityGates(config, getDefaultGates());
```

### checkQualityGates()

```typescript
import { checkQualityGates } from '@corpunum/lunum';

const { exitCode, result } = checkQualityGates(config);

// Use exit code for CI:
// 0 = pass, 1 = warn, 2 = fail
process.exit(exitCode);
```

### generateCIReport()

```typescript
import { generateCIReport, runQualityGates } from '@corpunum/lunum';

const result = runQualityGates(config, getDefaultGates());
const report = generateCIReport(result);
console.log(report);
```

## CI Configuration Example

### GitHub Actions

```yaml
- name: Quality Gate CI
  run: |
    node -e "
      const { checkQualityGates } = require('@corpunum/lunum');
      const { exitCode } = checkQualityGates();
      process.exit(exitCode);
    "
```

### GitLab CI

```yaml
quality_gate:
  script:
    - node -e "const { checkQualityGates } = require('@corpunum/lunum'); process.exit(checkQualityGates().exitCode);"
```

## Gate Results

Each gate returns a `GateCheckResult`:

```typescript
interface GateCheckResult {
  gate: string;          // Gate name
  result: 'pass' | 'warn' | 'fail';
  score: number;         // 0-1
  minimumScore: number;
  details: string[];
}
```

## Report Format

The CI report is a markdown document:

```markdown
# Quality Gate CI Report

## Summary
Status: PASS
Gates: 3/4 passed, 1 warned, 0 failed

- ✅ **sem-validation**: PASS (score: 1.00, minimum: 0.95)
  - All 6 test records validated

- ✅ **injection-resistance**: PASS (score: 1.00, minimum: 0.90)
  - All 10/10 adversarial inputs detected

- ⚠️ **renderer-conformance**: WARN (score: 0.90, minimum: 0.90)
  - test-with-annotations: short, tight

- ✅ **downstream-quality**: PASS (score: 0.85, minimum: 0.70)
  - Gate qa-gate: PASS

---
Generated by OpenLunum quality gate CI integration
```

## Integration Points

### With Existing Quality Systems

- **downstream-quality.ts** — Provides evaluateQuality for task success metrics
- **prompt-injection.ts** — Provides adversarial input testing
- **renderer-conformance.ts** — Provides profile round-trip canonicalization tests
- **context.ts** — Provides compileContext for natural vs Lunum vs mixed comparison

### With CI/CD

- Exit code 0 (pass) — merge allowed
- Exit code 1 (warn) — merge allowed with review
- Exit code 2 (fail) — merge blocked

## Testing

```bash
# Run quality gate CI tests
pnpm --filter @corpunum/lunum test:unit -- --test-name-pattern 'quality-gate-ci'
```

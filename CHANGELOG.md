# Changelog

All notable changes to OpenLunum will be documented here.

The project is pre-1.0. Semantic schema, fingerprint, rendering, and SDK compatibility are versioned independently where needed.

## 0.1.0 — 2026-07-15

### Added

- Established OpenLunum as the independent repository and Lunum-I as the independent specification line.
- Added draft Lunum-Sem and Lunum record schemas.
- Added deterministic canonicalization and versioned SHA-256 semantic fingerprints.
- Added conservative reference rendering and mixed-context compilation.
- Added a Unicode-preserving, explicitly non-semantic raw-text inspection path.
- Added CLI commands for encoding, inspection, validation, and context compilation.
- Added OpenUnum current-state analysis, gap analysis, adoption plan, adapter, and contract tests.
- Added design-stage adoption profiles for Claude Code, Codex CLI, Gemini CLI, OpenCode, Pi, and OpenClaw.
- Added historical evidence ledger and reproducible portable evaluation scripts.
- Preserved the complete initial Lunum handover under `research/archive/initial-handover`.

### Known limitations

- No production-grade multilingual semantic parser.
- No stable public protocol or package API.
- No current tokenizer-profile automation.
- No verified live product integration yet.
